# WebKit 실패 원인 메모 — 2026-11-04 밤 (프로젝트 타워)

## 한 줄
WebKit(사파리 엔진, Playwright 의 Windows 빌드) 실패는 **같은 PC 에서 다른 브라우저 테스트가 동시에 돌 때만** 났다. 혼자 돌리면 4번 연속 25/25 통과. 앱 버그로 보지 않는다 — 확신도 **추정**(8회 실행의 상관관계, 직접 원인을 잡은 것은 아님).

## 증상이 말하는 것
- 실패 지점이 매번 다르다(첫 버튼 클릭, 사진 넣기, 메뉴, 목록). 앱의 특정 기능이 아니라 **페이지가 통째로 멈춤**.
- '움직임 멈춤(stable)' 대기는 화면 프레임 두 장이 같아야 끝난다 — 120초 동안 못 끝난 것은 WebKit 이 프레임을 그리지 않았다는 뜻(확실: Playwright 동작 방식 / 추정: 렌더러 멈춤).
- 혼자 돌린 단계별 시간(같은 흐름 5회): 페이지 0.2~0.8초, 사진 0.1~0.7초, 흰 종이 보정 0.01~0.12초, 색 5개 1.7~3.9초 — 느린 곳 없음.
- 뺀 가설: trace(켜도 통과·꺼도 실패), 배경 블러(backdrop-filter, 껐다 켜도 차이 없음), 앱의 반복 작업(어울림 % 타이머는 꺼져 있음).

## 정한 것
- 앱 코드는 고치지 않는다. 테스트도 고치지 않는다(재시도·시간 늘리기로 덮지 않음).
- **WebKit 테스트는 다른 브라우저 테스트와 동시에 돌리지 않는다.** 실패가 나면 혼자 다시 돌려 본다.
- 남은 확인: 실제 iPhone Safari(이 Windows 빌드와 엔진은 같지만 그리기 방식이 다르다). 그건 사용자 폰으로만 된다.

## 다시 해 보는 법
