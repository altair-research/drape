# 테스터 모집 — Color Mirror 쪽 정리 (2026-10-26)

보낼 메시지는 **wearcast 저장소 `docs/TESTER-INVITE.md` §0 "두 앱 함께"** 를 그대로 쓴다.
테스터 이메일 목록 `internal` 은 개발자 계정 공통이라, 한 번 받은 주소로 WearCast 와 Color Mirror 가 동시에 14일을 채운다.
부탁은 한 번, 링크는 두 개. 여기에는 Color Mirror 쪽 콘솔 조작만 적는다.

## 순서

1. 메시지 1단계로 주소를 받는다 — **15명쯤**(12명이 최소, 한 명 빠지면 14일이 끊긴다). 안드로이드 필수, Gmail 아니어도 구글 계정이면 된다(`PLAY-STORE.md` §7-4).
2. 콘솔에 주소 넣기(아래). 목록에 한 번 넣으면 두 앱 모두에 들어간다.
3. Color Mirror 링크를 복사해 메시지 2단계의 `<Color Mirror 링크>` 자리에 넣어 보낸다.
4. 12명이 "테스터 되기"를 누른 날부터 14일. 날짜를 `HANDOFF.md` 머리말에 적는다.

## 콘솔에서 주소 넣기 (사용자, 5분)

화면 이름은 2026-09 콘솔 기준. 조금 다르면 비슷한 이름을 누르면 된다.

1. Play Console → 앱 목록에서 **Personal Color Mirror**
2. 왼쪽 **Test and release → Testing → Closed testing** → 트랙 **Alpha** 의 **Manage track**
3. **Testers** 탭 → 이메일 목록 `internal` 줄 오른쪽 **→(편집)** 아이콘
4. **Add email addresses** 칸에 받은 주소를 쉼표나 줄바꿈으로 붙여 넣고 Enter → **Save changes**
5. 같은 Testers 탭에서 `internal` 이 **체크돼 있는지** 확인(09-22 에 체크해 둠). 바꿨으면 아래 **Save**
6. 아래쪽 **Join on the web** 의 **Copy link** → 이게 보낼 Color Mirror 링크

WearCast 는 2~4번이 필요 없다(같은 목록). 5~6번만 WearCast 앱에서 한 번 더 한다.

## 테스터가 물어볼 만한 것

| 질문 | 답 |
|---|---|
| 링크가 "찾을 수 없음" | 폰 Play 스토어에 로그인된 계정이 알려준 주소와 다르다 |
| 카메라 영상이 어디로 가나 | 폰 밖으로 안 나간다. 서버가 없다(개인정보처리방침) |
| 의견은 어디로 | 앱 ⋯ 메뉴 → **의견 보내기**(v29 부터, 메일). 카톡으로 줘도 된다 |
| 친구에게 보여 주려면 | ⋯ 메뉴 → **친구에게 공유**(v29 부터). 링크로 브라우저에서도 열린다 |
