# 점수(어울림) 기능 — 다시 할지 논의 메모 (2026-11-05)

> 사용자 11-05: "점수화도 한번 생각해 보자. 어느 정도 될지 논의하고 준비. 일은 오늘 밤 10시 넘어서."
> 이 메모는 **결정용**이다. 코드는 아직 안 건드렸다.

## 1. 지금 남아 있는 것 (확실 — `index.html` "어울림 지수")
- 얼굴 가이드 안 볼·코 부분 피부색을 0.7초마다 읽어 Lab 색으로 바꾼다.
- 32색마다 ① 피부 노란기(웜/쿨) ↔ 색 온도 일치 60% ② 피부 맑기 ↔ 색 채도 일치 40% 로 원점수를 낸다.
- 32색 안에서 가장 낮은 걸 10, 높은 걸 100 으로 **늘려서** 보여 줬다.
- `MATCH_ENABLED = false` 로 꺼 둠(09-17 실기기 시험: 조명·각도에 따라 숫자가 흔들림).

## 2. 왜 흔들렸나 (원인 추정)
| 원인 | 확신 | 이번에 달라진 것 |
|---|---|---|
| 카메라 자동 색온도·밝기가 계속 바뀜 | 확실 | 빛 고정(안드로이드) + 흰 종이 맞춤(v34) 으로 줄일 수 있다 |
| 10~100 으로 늘리기 — 원점수 차이가 작아도 숫자가 크게 뜀 | 확실 (계산상) | 늘리지 않고 순위·구간으로 보여 주면 된다 |
| 0.7초마다 다시 읽음 — 고개만 돌려도 바뀜 | 확실 | "측정" 버튼 한 번에 3초 모아 고정 |
| 웜/쿨 기준(색상각 52°±12°)이 관행값 | 추정 | 사람마다 맞는지 근거 없음 — 실험 필요 |

## 3. 할 수 있는 방식 세 가지
1. **측정 한 번 → 상위 색 몇 개 '참고 순위'** (추천)
   - 흰 종이 맞춤을 먼저 해야 측정 버튼이 열린다. 3초 모아 한 번 재고, 숫자 대신 "잘 받는 쪽 5색 / 덜 받는 쪽 5색" 처럼 보여 준다.
   - "판정"이 아니라 참고라는 문구 유지(우리 차별점: 결과는 사용자 눈).
2. **색마다 % 다시 켜기** — 만들기는 쉽지만 9월과 같은 불만이 날 위험이 크다.
3. **카메라 없이 ♥ 기반** — 이미 '내가 고른 색' 요약으로 하고 있다.

## 4. "어느 정도 될지" 먼저 재 보는 실험 (오늘 밤 AI 몫 + 사용자 폰 5분)
- 화면에 안 보이는 **실험 모드**(`?score=1` 주소로만 열림)를 만든다.
- 사용자: 방 2곳(예: 거실 조명·창가) × 각 3번, 흰 종이 맞춘 뒤 측정 → 화면에 나온 상위 5색을 캡처.
- 통과 기준(제안): **같은 사람 6번 측정에서 상위 5색 중 3색 이상이 늘 겹침.** 넘으면 방식 1 로 화면에 넣고, 못 넘으면 출시 뒤로 미룬다.
- 숫자 근거: 5색 중 3색 = 과반이 겹쳐야 사용자가 "매번 다르다"고 느끼지 않는다고 본 값(추정, 조정 가능).
